# Сайт для расписания (GitHub Pages)

Ты правишь расписание на сайте, нажимаешь «Опубликовать» — приложение само подтягивает новое. Обновлять приложение не нужно.

## Один раз настроить

1. Зарегистрируйся на github.com (бесплатно).
2. Создай репозиторий: **New repository**, имя например `raspisanie`, вид **Public** (нужен для бесплатных Pages и ссылки для приложения). Поставь галочку «Add a README».
3. В репозитории нажми **Add file → Upload files** и загрузи из этой папки три файла: `index.html`, `schedule.txt`, `.nojekyll`. Нажми **Commit changes**.
   (Если `.nojekyll` не виден в проводнике, он не обязателен — можно пропустить.)
4. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)`, **Save**. Через 1–2 минуты сайт будет по адресу `https://ТВОЙ_НИК.github.io/raspisanie/`.
5. Создай токен, чтобы сайт мог сохранять: **Settings (профиля) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Repository access: *Only select repositories* → `raspisanie`
   - Permissions → Repository permissions → **Contents: Read and write**
   - Срок можно поставить подольше. Скопируй токен (`github_pat_…`), он показывается один раз.
6. Открой свой сайт, в блоке «Подключение к GitHub» вставь токен (репозиторий определится сам) → **Сохранить и загрузить расписание**.
7. Скопируй «Ссылку для приложения» (кнопка «Копировать»). Она выглядит так:
   `https://raw.githubusercontent.com/ТВОЙ_НИК/raspisanie/main/schedule.txt`
8. В приложении: **☁ Расписание с сайта** → вставь ссылку → **Сохранить и обновить**.

## Каждый день

Открой сайт → поменяй уроки/кабинеты/звонки → **Опубликовать**. Приложение проверяет сайт при открытии, при обновлении виджета и при уведомлениях (не чаще раза в 30 минут). Сразу: в приложении «☁ Расписание с сайта» → «Сохранить и обновить». GitHub может держать кэш до ~5 минут.

## Важно

- Репозиторий публичный: расписание увидит любой, у кого есть ссылка. Личного там ничего не храни.
- Токен хранится только в браузере, где ты его вставил. Не отправляй его никому и не клади в репозиторий. Если потерял — удали токен на GitHub и создай новый.
- Расписание с сайта заменяет правки, сделанные вручную в приложении.
- Нужен интернет только для обновления; без него приложение показывает последнее сохранённое расписание.
